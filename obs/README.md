# Integração com OBS Studio

Duas estratégias, em ordem:

1. **Câmera virtual do Windows** (`virtual-camera/`): o OBS vê "iCam Studio 4K" como webcam. Sem plugin no OBS. Fase 4.
2. **Plugin libobs em C/C++** (`plugin-libobs/`): fonte nativa do OBS. Futuro.
